# Security & Disclosure Policy

This repository is intentionally separated from the production repository.

## Never commit here

- API keys, tokens, passwords or credentials;
- `.env` files or deployment configuration containing real values;
- customer or pilot data;
- private documents, briefs, exports or screenshots containing identifiable data;
- production database schemas or migrations;
- internal AI prompts, orchestration rules, evaluation rubrics or decision logic;
- production URLs or identifiers that expose internal infrastructure;
- source copied from the private product kernel.

## Demo-data rule

Every person, company, metric, action and result shown in this repository must be synthetic or clearly generic.

## Reporting

If you believe this repository exposes sensitive information, do not open a public issue containing that information. Contact the repository owner privately.
